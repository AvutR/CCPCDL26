# Discussion and Limitations

The model deliberately abstracts away several real-world details, including control-plane delays, heterogeneous node topologies, and live production workloads. These simplifications are intentional and should be interpreted as assumptions required to create a tractable comparison among scheduling strategies.

The conclusions of this project are therefore relative rather than absolute: they indicate how different scheduling policies behave under a calibrated shared-pool simulation, not whether any method is universally optimal in production.
