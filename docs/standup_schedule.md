# Sprint Standup Schedule

This project should maintain visibility across the remaining days so integration issues get caught before they turn into day-3 crises.

## Recommended cadence

- Team standup: 10 minutes every morning, same time each day
- Optional async check-in: 5–10 minutes in the group chat each afternoon if work is drifting or blockers appear

## Suggested time

- Daily standup: 9:30 AM local time
- Default sync channel: project chat / group messaging thread
- Hard blocker escalation: if simulator or generator is not on track by noon on Day 2, the team should immediately reassign help to unblock that dependency

## Agenda

1. What was completed since the last check-in?
2. What is blocked or at risk?
3. What needs help from another owner today?
4. Any integration mismatches with the trace schema or policy interface?
